# Middleton et al. Saliva reference pheno data

The phenotype data of GSE147318

## Usage

``` r
Middleton_pd
```

## Format

### 

A dataframe of 60 rows and 1 column This data contains the cell type
label of the Middleton saliva reference, allowing for usability of the
[`getRef()`](https://maggie-fu.github.io/CellsPickMe/reference/getRef.md)
function when Middleton reference is called. The data is extracted from
GSE147318, a dataset created and published by Middleton et al. Please
cite the following if using this data. Middleton LYM, Dou J, Fisher J,
Heiss JA et al. Saliva cell type DNA methylation reference panel for
epidemiological studies in children. Epigenetics 2022
Jan-Feb;17(2):161-177. PMID: 33588693
